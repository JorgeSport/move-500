Revista comercial independiente, adaptable a móvil y escritorio, sobre el bolso Decathlon Move 500 de 25 litros.

## Uso

Sitio estático: `index.html`, `style.css`, `app.js` e `images/`. Publicar desde la raíz con GitHub Pages. Sin dependencias de ejecución.

Dos colores: verde salvia (8940714) y negro ahumado (8940713). Cinco fotos por color, alojadas en este repositorio.
